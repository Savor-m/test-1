CORE SESSIONS TRACKER — PWA iPhone

Fonctions incluses
- Jour 1 et Jour 2, mêmes titres que les infographies
- Navigation exercice par exercice
- Illustration simple de chaque type de mouvement
- Lien YouTube ciblé par exercice
- Saisie de 3 séries: poids, répétitions, secondes
- Notes par exercice
- Douleur articulaire avant/après
- Historique des séances
- Graphique simple de progression par exercice (meilleur poids saisi)
- Export CSV complet
- Données stockées localement sur l’iPhone
- Mode hors ligne après installation/chargement initial (si servi en HTTPS)

IMPORTANT
Pour être installée comme vraie PWA sur l’écran d’accueil, l’application doit être publiée sur une adresse HTTPS.
Une fois publiée : Safari > Partager > Sur l’écran d’accueil.
